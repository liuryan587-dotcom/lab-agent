## 三、yield 实验（2:20–3:20）

`backend/app/database.py` 第 12–17 行：

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**✍️ 实验 1：把它当普通函数看**

- `type(g)` 是什么？

  > ✍️<class 'generator'>

- 调用 `get_db()` 得到的是 session 还是别的？
  > ✍️<generator object get_db at 0x00000212AA31DE50>,是一个generator对象

**✍️ 实验 2：看它停在哪**

```powershell
uv run python -c "import app.database as d; g = d.get_db(); s = next(g); print(s); g.close()"
```

- `next(g)` 返回什么？
  > ✍️<sqlalchemy.orm.session.Session object at 0x000002F31C64D2B0>返回的是session对象

**✍️ 实验 3：回答三连**

1. 为什么请求结束 `db.close()` 一定会执行？

   > ✍️这是语法决定的，无论try中是否抛出问题，都会执行finally

   > ✍️会
