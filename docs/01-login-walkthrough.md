> **配合 [L1-学习计划.md](L1-学习计划.md) 的 Day 2 / Day 3 / Day 4 使用，不替代它们。**
> 这份文件只补一件事：你现有计划里所有作业都是「自己写笔记」，**没有一条是「讲出来、被人挑错」**。
> 而「讲不出来就是没懂」——这是你判断自己真实水平唯一可靠的方式。

## 怎么用

1. 先按 L1 计划做完对应的阅读和实验（Day 2 读 `auth_service.py`，Day 3 读前端链路，Day 4 做 Network 实战）。
2. 然后回到这份文件，**找对应阶段的自测题，脱稿回答**。
3. 答完**讲给我听**（把答案发给我）。我会像面试官一样追问，指出你漏掉和讲错的地方。
4. 我挑出的问题，记进你的 `notes/错题本.md`。

**规则**：
- 不许翻代码、不许查资料。**想了 30 秒想不起来就是没懂**，直接说"这题不会"比硬编强。
- 回答要说**具体值**，不许说"大概是一个对象"。比如「`user` 是 `User` 对象，`user.username` 是 `"zhangsan"`」。
- 讲不出来的题，就是你的短板清单。

## 复述规则：怎么「讲给我听」

不要只发答案，用这个格式，这样我才能判断你是真懂还是背的：

```
阶段 1
第 1 题：login() 有 3 种失败情况……
   ① 查不到用户 → 第 17 行 raise BusinessException("账号或密码错误")
   ② 密码不对 → 同一行（条件用 or 合并了）
   ③ 用户被禁用 → 第 20 行
第 2 题：……
不确定的：第 5 题我只会说"因为有 salt"，但说不清比对过程
```

**"不确定的"这一栏最重要。** 主动说出边界，比假装全会得分更高——面试时也一样。

## 卡住了怎么问

**先自己试，再问我。** 问的时候用这个格式：

```
我在做：阶段 1 第 3 题
我以为：FastAPI 会……
我实际看到：终端打印了……（贴真实输出）
我卡在：为什么它不是我以为的那样
```

**不要问「这段代码什么意思」**（那是让我替你读代码）。
**要问「我猜是 A，但结果是 B，为什么」**（那说明你在思考，我只补最后一块砖）。
